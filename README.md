# 原神抽卡记录查询（国服 · Windows）

读取你电脑上游戏留下的缓存，找到官方的祈愿记录接口链接，把抽卡记录取回来，在本机统计并保存。

## 它是怎么工作的

1. 你在游戏里打开「祈愿 → 历史记录」时，游戏内置的网页会请求官方接口，这个请求地址（带有一个临时的 `authkey`）会被写进游戏目录下的缓存文件 `YuanShen_Data\webCaches\...\data_2`。
2. 本程序**只读**这个文件，找出最新的那条链接，再用它去请求官方的祈愿记录接口，每个卡池一页页取回。
3. 记录保存在本程序旁边的 `data` 文件夹里（每个 UID 一个文件）。以后每次更新都会合并新记录，不会重复。

不改游戏文件、不监听网络流量、不注入游戏进程，所以没有封号风险；记录只存在你自己电脑上，程序只会把链接发给 `*.mihoyo.com`。

## 使用方法

第一次需要装 Python（只装一次）：到 <https://www.python.org/downloads/> 下载 Python 3，安装时**勾选 "Add python.exe to PATH"**。

然后每次：

1. 打开原神，进入「祈愿」→ 左下角「历史记录」，随便点开一个卡池翻一翻（这一步会让游戏把链接写进缓存，**每次更新前都要做**，链接约 24 小时失效）。
2. 双击 `启动.bat`（Mac 双击 `启动.command`），会弹出一个黑色窗口，随后浏览器自动打开界面。
3. 点右上角「更新记录」。

用完关掉黑色窗口即可退出。

> **不要直接双击 `index.html`**，那样只会看到一个空页面。必须先用上面的启动文件，让程序跑起来，页面才有内容。
> Mac 上没有这个游戏的缓存，所以只能打开界面看看，取不到记录；真正查记录要在玩游戏的 Windows 电脑上做。

> 游戏开着或关着都可以读取。如果自动找不到游戏目录，点界面上的「高级」，填入游戏安装目录（里面有 `YuanShen.exe` 的文件夹），或者直接粘贴祈愿链接。

## 功能

- 角色 / 武器 / 集录 / 常驻 / 新手 五个卡池分开统计
- 当前保底进度条、五星平均抽数、每个五星是第几抽出的（绿 / 黄 / 红按保底远近上色）
- 全部记录表格，可只看四星以上或五星
- 多个 UID 可切换
- 导出 CSV（Excel 可直接打开中文）和 JSON

## 注意事项

- **官方只保留最近半年的记录**，所以隔一阵更新一次，更早的记录才会被攒在本地。**请备份 `data` 文件夹**，它是你唯一的完整存档。
- 祈愿链接相当于一把 24 小时有效的钥匙，别发给不信任的人。
- 「常驻」标记：活动池里出了常驻五星角色，多半是歪了。但这些角色自己 UP 的复刻池里出了不算歪，从记录里无法区分，所以只做标记、不统计成"歪了几次"。常驻角色名单在 `wishlog/pools.py`，游戏更新后可以直接改。
- 保底抽数（角色 90、武器 80、集录 90）只用来画进度条和上色，若游戏规则调整，改 `wishlog/pools.py` 里的数字即可。
- 目前只支持原神国服（官服 / B服）。

## 出问题时

| 提示 | 怎么办 |
| --- | --- |
| 页面显示“需要先启动程序” | 说明程序没在运行（直接打开了网页文件，或黑色窗口被关了）。重新双击启动文件 |
| 没能自动找到游戏目录 | 先启动一次游戏；还不行就在「高级」里填游戏安装目录 |
| 没有找到游戏的网页缓存 / 缓存里没有祈愿链接 | 在游戏里打开「祈愿 → 历史记录」翻一翻，再更新 |
| 祈愿链接已经失效 | 同上：重新打开一次历史记录页面再更新 |
| 官方接口提示访问过于频繁 | 等几分钟再试 |

## 打包成 exe（Windows，免装 Python）

PyInstaller 只能在 Windows 上打出 Windows 的 exe。有两种办法，打出来的 `GenshinWishLog.exe` 都是单个文件，**用它的电脑不需要装 Python**：

**办法 A：在 Windows 电脑上打包**（不用注册任何账号）
把整个文件夹复制到 Windows 电脑，装好 Python 3（只有打包这一步需要），双击 `打包成exe.bat`，完成后在 `dist` 文件夹里拿到 `GenshinWishLog.exe`。

**办法 B：用 GitHub 云端打包**（打出来的 exe 会在真正的 Windows 上自动跑一遍测试和冒烟检查）
把这个文件夹传到你自己的 GitHub 仓库（`.gitignore` 已经排除了 `data/`，你的抽卡记录不会被传上去），进入仓库的 Actions 页面，选 `build-windows` → `Run workflow`，几分钟后在这次运行页面底部下载 `GenshinWishLog`（里面是 exe）。给仓库打上 `v0.1.0` 这样的标签，还会把 exe 放到 Releases 页面，得到一个固定的下载链接。

用法：把 exe 放进一个固定的文件夹（比如 `D:\原神抽卡记录\`），双击运行，浏览器自动打开界面。记录保存在 exe 旁边的 `data` 文件夹里，所以**不要直接在压缩包里运行，也不要只搬走 exe 而留下 `data`**。

首次运行时 Windows 可能提示“Windows 已保护你的电脑”（SmartScreen）：这是因为程序没有付费的代码签名，点「更多信息」→「仍要运行」即可。部分杀毒软件也可能误报 PyInstaller 打出来的程序，需要的话把它加入信任。

## 开发

只用 Python 标准库，没有第三方依赖。

```bash
python -m unittest discover -s . -p "test_*.py" -t .   # 跑测试（假接口 + 假缓存文件）
python -m wishlog --no-browser                         # 不开浏览器启动
```

目录结构：

- `wishlog/locate.py` 找游戏目录、读缓存、取链接
- `wishlog/client.py` 官方接口客户端（域名白名单、翻页、重试、过期判断）
- `wishlog/sync.py` 增量抓取，按卡池提交
- `wishlog/store.py` 本地存储与去重
- `wishlog/stats.py` 保底与出金统计
- `wishlog/server.py` / `job.py` / `static/index.html` 本地网页界面
- `run.py` 打包成 exe 的入口；`打包成exe.bat`、`.github/workflows/build-windows.yml` 是两种打包方式
